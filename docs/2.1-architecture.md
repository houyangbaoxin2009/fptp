# Osiris 1.0.0 架构（Avalonia 跨平台重写）

> 版本：1.0.0.0　|　日期：2026-08-11　|　状态：Oracle 架构决策已冻结
> 前身：2.0 WinForms 版（已归档 `docs/archived/2.0-architecture-winforms.md`）

## 1. 目标

完全推倒 2.0 增量演进的代码，用现代 .NET 栈重写为**真正跨平台**（Win/macOS/Linux）的 **PS 级模块化图像编辑器**：

- 单一 TFM `net10.0`（弃 netstandard2.0 与 `net10.0-windows`）
- UI 壳：**Avalonia 12**（替换 WinForms）
- **界面完全由模块控制**：壳 = 模块运行时 + 空工作台框架（窗口/菜单栏容器/工具栏容器/dock 面板/画布宿主），**零业务 UI**；菜单、工具栏、面板、画布、工具、设置全部由模块贡献
- **模块注册表系统**：记录全部模块的信息与配置（JSON 持久化），支持启用/禁用/卸载
- **模块分级与权限**：内置模块（Standard，随产品分发，用户不可卸载/禁用/更改其文件——仅**内置更新模块**可更改；但**用户可更改其设置/配置**）+ 扩展模块（Extension，用户可自由安装/卸载/更改，ALC 动态加载）+ **更新模块**（Update，内置特殊模块，唯一有权替换/更新内置模块文件与安全设置）
- **设置分级**：用户设置（User，用户可改）+ 核心设置（Core，用户可改）+ 安全设置（Security，仅更新模块可改）；设置面板只展示 User/Core，Security 隐藏
- **模块与更新模块交互**：普通模块可经 `IModuleUpdater` 通用面查询更新状态/请求更新/订阅更新事件/读取安全设置；替换内置模块与写安全设置仅 Update 模块可用
- 代码与成品高度模块化：契约/实现/渲染/标准模块/壳/CLI/扩展模块分层
- 插件系统保留且可卸载（ALC），**ABI 红线**保证卸载承诺
- 功能集完整保留：证件照全流程（智能裁切/换底/灰度/排版）、撤销重做、图层、套索、批量处理、动漫滤镜、JSON 配置面板
- 长期愿景：媲美 PS（图层/蒙版/选区/滤镜/脚本），2.1 先建立模块化骨架与证件照工作流
- **CLI 模块化**：CLI 与 GUI 同为模块宿主，共享同一模块系统（注册表/权限/安全设置/ALC 加载）；模块经 `ICliCommandProvider` 贡献 CLI 子命令（声明式描述，tie 友好）；无 UI 宿主时模块跳过 UI 注册、注册 CLI 命令
- **tie 语言预留（Leibniz = tie）**：模块开发与脚本自动化未来将使用自研 tie 语言（2.0 规划中的 Leibniz 脚本桥即 tie 的实现）。模块描述数据化（module.json 清单含 Language/EntryPoint），契约保持语言中立（纯数据 + 简单类型），tie 宿主（标准模块，TieHost）后续接入，现有 .NET 模块不受影响。
  - tie 接入点：`IHostContext` 同一接口面（tie AST 解释执行直接调用）；`FilterParameters`/`FilterParameterDescriptor` 声明式自描述（tie 可直接构造）；`BatchStep` 数据化（tie 可描述批处理链）；未来 tie 滤镜可编译到 SkSL 走 GPU。
  - **tie:data 全面取代 JSON**：未来所有配置（模块注册表 modules.json、模块配置 settings.json、模块清单 module.json）将迁移到 tie:data 格式。**配置持久化必须格式中立**：Core 提供 `IConfigStore` 抽象（Load/Save 数据面），当前实现 `JsonConfigStore`（System.Text.Json），未来实现 `TieDataConfigStore` 无缝替换，注册表/配置层只依赖接口。

### 4.6 模块体系（注册表与分级）

```csharp
public enum ModuleKind { Standard, Extension, Update }
// Standard=内置（用户不可拆卸/更改，仅 Update 模块可改）
// Extension=扩展（用户可安装/卸载/更改）
// Update=内置更新模块（特殊权限：唯一可替换/更新内置模块）

public enum ModuleStatus { Enabled, Disabled, Removed } // Removed=已卸载（避免重复加载）
public enum ScriptLanguage { DotNet, Tie }            // 实现语言（tie 预留）
public enum ModuleType { Native, Script }             // Native=程序集 / Script=tie 脚本

public sealed record ModuleRecord(
    string Id, string Name, string Version,
    ModuleKind Kind, ModuleStatus Status,
    ModuleType Type, ScriptLanguage Language,
    string? EntryPoint,       // Native: dll 路径；Script: .tie 文件路径
    string? LoadPath);        // 程序集目录（Native）

public interface IModule : IPlugin
{
    ModuleKind Kind { get; }
    IReadOnlyList<string> Dependencies { get; }   // 依赖模块 Id（可选）
}

/// <summary>
/// 用户面注册表。权限规则：
/// - 对 Standard 的 SetEnabled/MarkRemoved 一律拒绝（抛 InvalidOperationException）——用户不可禁用/卸载内置模块；
/// - SetConfig/GetConfig/ResetConfig 对全部模块（含 Standard）开放——用户可更改内置模块的设置。
/// </summary>
public interface IModuleRegistry
{
    IReadOnlyList<ModuleRecord> Modules { get; }  // 全部记录（含 Removed）
    void Register(ModuleRecord record);           // 从 module.json / 反射登记
    ModuleRecord? Get(string id);
    bool IsEnabled(string id);                    // 未记录默认 true
    void SetEnabled(string id, bool enabled);     // 仅 Extension 可操作（Standard 拒绝）
    void MarkRemoved(string id);                  // 仅 Extension 可操作（Standard 拒绝）
    T? GetConfig<T>(string moduleId, string key, T? fallback = default);
    void SetConfig(string moduleId, string key, object? value);  // 即时 JSON 落盘（全部模块开放）
    void ResetConfig(string moduleId);
}

/// <summary>
/// 模块更新交互服务（经 host.Services.Get&lt;IModuleUpdater&gt;() 获取，所有模块可用）。
/// 权限分级：
/// - 通用面（所有模块可调）：GetUpdateStatus / RequestUpdate / UpdateStatusChanged 事件 / GetSecurityConfig（安全设置可读不可写）；
/// - Update 专用面（实现校验调用方 Kind=Update）：ReplaceStandardModule（替换内置模块文件）/ SetSecurityConfig（写安全设置）。
/// 2.1 实现本地状态与文件替换骨架（下载/签名校验后续版本补充）。
/// </summary>
public interface IModuleUpdater
{
    // ---- 通用面：模块与更新模块交互 ----
    UpdateStatus GetUpdateStatus(string moduleId);
    void RequestUpdate(string moduleId);
    event EventHandler<UpdateStatus>? UpdateStatusChanged;
    T? GetSecurityConfig<T>(string moduleId, string key, T? fallback = default);

    // ---- Update 专用面（校验调用方 Kind=Update）----
    bool ReplaceStandardModule(string moduleId, string newVersion, string packagePath);
    void SetSecurityConfig(string moduleId, string key, object? value);
}

/// <summary>模块更新状态（通用面返回）。</summary>
public sealed record UpdateStatus(string ModuleId, string InstalledVersion, string? LatestVersion, bool UpdateAvailable, string? Message);
```

### 4.7 模块清单（module.json，语言中立）

每个模块（标准与扩展）根目录放 `module.json`，注册表数据源；反射扫描为兜底。**清单文件格式中立**：当前 JSON，未来 tie:data（经 IConfigStore 抽象解析，模块作者无感）：

```json
{
  "id": "fptp.idphoto",
  "name": "证件照扩展模块",
  "version": "1.0.0.0",
  "kind": "extension",          // standard | extension
  "type": "native",             // native | script
  "language": "dotnet",         // dotnet | tie

  "minHostVersion": "1.0.0.0",
```

- Native 模块：`entryPoint` 为 dll 文件名，宿主反射扫描 `[PluginExport]` 实现 `IModule` 的类型。

- `FilterParameters` / `FilterParameterDescriptor` / `BatchStep` 保持声明式数据（tie AST 可直接构造）。

## 5. ABI 红线（强制，配契约测试）

1. **插件程序集不得引用 `SkiaSharp` / `Avalonia` / `System.Windows.Forms`**。滤镜只操作 `PixelSurface`（byte[]），渲染由宿主完成。native 依赖无法随 ALC 卸载。
2. **契约内禁止出现 SK/Avalonia 类型**（`Osiris.Abstractions` 引用白名单：仅 System.*）。
3. `Osiris.Abstractions.dll` **不得复制进插件输出目录**。
4. 契约测试：反射读取插件程序集引用表，断言不含红线程序集。

## 6. 文档模型与历史（COW）

- `PixelSurface`：`byte[]` BGRA 预乘 8bit + 尺寸。**只读**访问（`ReadOnlySpan<byte> Pixels`、`int Width/Height`、`int RowBytes`）。
- 编辑路径：`PixelSurface.CreateEditor()` → `PixelSurfaceEditor`（可变缓冲 + 脏矩形跟踪）→ `Commit()` 返回新 `PixelSurface`。
- `Layer` **不可变**：`record`，含 `Id/Name/Visible/Opacity/BlendMode/OffsetX/OffsetY/Pixels`；派生用 `with` / `WithPixels()`。
- `OsirisDocument`：`Width/Height/Layers/History/Selection`。
- 历史：`IUndoableCommand { void Execute(DocumentState); void Undo(DocumentState); void Redo(DocumentState); }`，`HistoryStack` 深度 30~50，命令级粒度（一次用户操作 = 一个命令）。
  - `ApplyFilterCommand { layerId, oldLayer, newLayer }` —— oldLayer 即变换前不可变引用，撤销 = 指针回退，零拷贝。
  - `SelectionEditCommand` —— 套索一笔一个命令（不是每鼠标事件一个）。
- 零拷贝 SKImage 视图：`ZeroCopyImage.Create(PixelSurface)` 用 `SKData.Create(IntPtr, length, releaseDelegate)` no-copy 包装 array + `GCHandle.Alloc(pinned)`，SKData 释放句柄；`SKImage.FromPixelData(SKImageInfo(Bgra8888, Premul), ptr, rowBytes)`。

## 7. 渲染协议（CanvasControl）

- **方式**：`Control.Render(DrawingContext)` → `context.Custom(new CanvasDrawOperation(bounds))`，op 的 `Render(ImmediateDrawingContext)` 里 `TryGetFeature<ISkiaSharpApiLeaseFeature>()` → `lease.SkCanvas` 直绘。零拷贝、自动 DPI。
  - 待验证（Avalonia 12 API 形态）：若 `ICustomDrawOperation` 被 `RenderOperation` 替代，用新版等价 API，语义不变。
- **视口状态**：`(double OffsetX, OffsetY, double Scale)`。渲染：`canvas.Translate(OffsetX, OffsetY); canvas.Scale(Scale)`。
- **缩放锚定公式**（滚轮/捏合在控件坐标 p，目标缩放 s′）：`Offset′ = p − (p − Offset) × (s′/s)`。
- **命中测试**：`inverse(M) × e.GetPosition(this)` → 文档像素坐标 → 组 `ToolMouseEvent` 交给 `IEditorTool`。
- **性能**：渲染前反算可见文档矩形，只画相交图层；`Revision` 计数器变化触发 `InvalidateVisual()`。
- 平移：中键或空格+左键拖拽。

## 8. 模块系统（加载与生命周期）

### 8.1 加载流程（App 启动）

1. 壳构建 DI 容器 + `ModuleRegistry`（读 `%APPDATA%/Fptp/modules.json` 恢复状态与配置）。
2. **标准模块**（Kind=Standard）：编译时静态引用（Osiris.CoreModule），启动即 `Initialize`，注册表登记 Enabled（不可禁用/卸载）。
3. **扩展模块**（Kind=Extension）：扫描 `plugins/` 与 `%APPDATA%/Fptp/modules/` 两个目录：
   - 读 `module.json` 清单 → 构造 `ModuleRecord`（状态取注册表：Disabled 跳过、Removed 不加载）。
   - 无清单时兜底反射扫描 dll。
   - Native：每模块独立 `AssemblyLoadContext(name, isCollectible: true)` + `AssemblyDependencyResolver` 加载。
   - Script/tie（未来）：交给 TieHost 标准模块。
4. `MinHostVersion` 校验不满足 → 记入注册表（Status=Disabled + 错误信息），不加载。

### 8.2 卸载纪律（ALC）

- 扫描后不缓存 `Type/Assembly`；插件实例被事件订阅持有即无法回收。
- `Unload()` 流程：摘除事件订阅 → 释放实例引用 → `alc.Unload()` → `GC.Collect()` → WeakReference 断言可回收（Plugins.Tests 验证）。
- **ABI 红线**：插件程序集不得引用 SkiaSharp/Avalonia/WinForms；`Osiris.Abstractions.dll` 不复制进插件目录。

### 8.3 启用/禁用/卸载（模块管理面板）

- 禁用：`SetEnabled(id, false)` → 下次启动不加载（JSON 持久化）。
- 卸载：`MarkRemoved(id)` → 记录 Removed + 删除模块文件（防重复加载；可重新安装）。

## 9. 模块配置系统

- 模块经 `ISettingProvider.Groups` 贡献设置组（`SettingItem` 类型树：Bool/Number/Text/Choice/Color/FilePath）。
- 壳聚合全部组 → `SettingsWindow` 左导航 + 右侧 DataTemplates 自动生成控件（零转换器）。
- 编辑即 `IModuleRegistry.SetConfig(groupId, key, value)` 即时落盘（扁平结构 `{模块Id:{键:值}}`）。
- 值类型：bool / double / string / uint(PackBgra)。损坏文件重置为空。
- 路径：`%APPDATA%/Fptp/settings.json`（Linux `~/.config/Fptp/settings.json`），经 `IAppPaths` 注入（CLI 可 `--config` 覆盖）。

### 9.0 设置分级（User / Core / Security）

```csharp
public enum SettingScope { User, Core, Security }
// User：用户设置（面板展示，用户可改）
// Core：核心设置（面板展示，用户可改——决定软件核心行为的参数）
// Security：安全设置（面板隐藏，仅更新模块经 IModuleUpdater.SetSecurityConfig 可改；普通模块/用户可读不可写）
```

- `SettingItem` 增加 `SettingScope Scope`（默认 User）。注册表 `SetConfig` 写权限校验：查该键声明级别——Security 键拒绝用户面写入（抛 InvalidOperationException），User/Core 开放。
- **存储隔离**：settings.json 存 User/Core 段；**secure.json 存 Security 段**（用户直接编辑 settings.json 也无法触碰安全设置）。
- 设置面板只渲染 User/Core 项，Security 项隐藏。

### 9.1 持久化格式中立（tie:data 预留）

配置与注册表存储经 **`IConfigStore`** 抽象（Core 定义）：

```csharp
public interface IConfigStore
{
    // 数据面：扁平键值（组.键 -> 值），值与 JSON/tie:data 标量一一对应
    IReadOnlyDictionary<string, object> Load(string filePath);
    void Save(string filePath, IReadOnlyDictionary<string, object> data);
}
```

- `JsonConfigStore`（当前）：System.Text.Json，扁平结构即时落盘，损坏文件返回空。
- `TieDataConfigStore`（未来）：tie:data 序列化，实现同接口即无缝切换，注册表/面板/模块零改动。
- 模块清单（module.json）解析同样经此接口（当前 JSON 实现）。

## 10. 批处理与 CLI

- `BatchProcessor`（Core）：输入文件列表 + `IReadOnlyList<BatchStep>`（滤镜链步骤）+ `IProgress<BatchProgress>` + `CancellationToken` → 逐张执行。**零 UI 依赖**。
- CLI：`System.CommandLine` 根命令 `osiris batch <dir> --filter 灰度 --filter 换底 --out <dir>`，复用同一 `BatchProcessor`，进度打控制台。
- App：`BatchViewModel` 调同一 `BatchProcessor`，进度条接 UI 线程（`Dispatcher.UIThread`）。

## 11. 跨平台注意

- 文件对话框：`IFileDialogService`（App 实现，包 `TopLevel.StorageProvider.OpenFilePickerAsync/SaveFilePickerAsync`；Linux 走 XDG portal）。**禁用已废弃的 `Avalonia.Controls.FileDialog`**。
- 路径：`IAppPaths` 抽象，`Environment.SpecialFolder.ApplicationData + "Fptp"`。
- 图标：`Assets/` 资源（Avalonia 用 `.ico` 生成平台图标）。
- 线程：批处理/滤镜在后台线程，回传 UI 用 `Dispatcher.UIThread.Post`。

## 14. 传统编辑三模块（老版 FPTP 功能集合，除滤镜）

原「传统编辑模块」fptm 已拆分为三个独立扩展模块（2026-08-14，各自独立 ALC 加载）：

- **itool（画笔工具模块，`plugins/Itool`，id="itool"）**：9 个编辑工具 + 画笔窗口 + 颜料盘 + 工具状态。
  - 工具（实现 IEditorTool，画布像素坐标事件，绘制经 PixelSurfaceEditor → Commit → COW 历史一笔一命令）：选取（矩形选区）/ 套索（多边形选区）/ 智能框选（魔棒，颜色容差 flood-fill）/ 滴管（取色）/ 铅笔（1px 硬边）/ 钢笔（硬边圆点，1~10px）/ 毛笔（软边径向衰减笔刷，如 8px）/ **刷子（多毛刷痕：沿笔画方向绘制 N 根平行毛线，毛的粗细与偏移从中间向两边逐步减小——中间粗浓、两边渐细渐淡，形如现实刷子刷过的印记；毛数随尺寸自适应 5~13 根）**/ 颜料桶（flood-fill 填充）。**每种画笔工具独立选择颜色**（工具各自持颜色 + 大小，经 itool.tools 设置组持久化）。
  - **画笔窗口**（可停靠）：工具切换 + 颜色/大小 + 颜料盘 + 预设栏。
  - **颜料盘**：9 个颜色槽位，可保存/加载颜色配置（itool.palette 设置组，User 级，JSON 即时落盘）；点击槽位设为当前画笔颜色；**预设栏**保存/加载整套画笔颜色（itool.hotkeys 快捷键 Ctrl+B+1~9）。
  - 快捷键：颜料盘槽位 1~9 默认 **Ctrl+A+1~9**（`itool.paletteN` 命令，壳 KeyDown 路由执行）。
- **fpedit（编辑模块，`plugins/FpEdit`，id="fpedit"）**：编辑命令 + 操作窗口。
  - **操作窗口**（可停靠）：选取/套索/智能框选/滴管工具切换 + 复制/粘贴/撤销/重做（fpedit.copy/paste/undo/redo 命令，快捷键 Ctrl+C/V/Z/Y，经 fpedit.hotkeys 设置组）。
  - **像素剪贴板**：模块内跨文档复制/粘贴缓冲（不碰系统剪贴板）。
- **fptm（传统面板模块，`plugins/Fptm`，id="fptm"）**：仅保留老版面板。
  - **fptm 老版面板**（可停靠）：老版 FPTP 工作流（批量处理表单 / 打印 / 排版预设），复用 Core BatchProcessor / LayoutProcessor。

- 接口契约：工具模块入口 `ITool`（原 IToolPlugin，全库更名）；`IToolHostService` 提供 `ActivateTool(toolId)` 与 `CurrentToolId`（当前激活工具，itool 取色/颜料盘目标工具判断经此查询——拆分后各模块独立 ALC，不能共享模块内静态状态）。
- 模块文件：`plugins/Itool/Itool.csproj`、`plugins/FpEdit/FpEdit.csproj`、`plugins/Fptm/Fptm.csproj`（均输出 plugins/bin 子目录，各自 module.json，kind=extension）。

### 14.1 算法库（Osiris.Algorithms，模块开发者公共库）

**动机**：扩展模块因 ABI 红线不能引用 Core，导致滤镜/工具算法各自重复实现（flood-fill、Bresenham、软边笔刷、缩放、量化等）。独立纯算法库解决：

- **项目**：`src/Osiris.Algorithms/`（net10.0，仅引用 Abstractions 的 PixelSurface/Selection/Point2 类型，零 UI/渲染依赖）。
- **ABI 红线更新**：扩展模块允许引用 `Osiris.Abstractions` + `Osiris.Algorithms`（两者均无 UI/渲染依赖，插件 ALC 共享程序集名单加入 Osiris.Algorithms）；仍然禁止 SkiaSharp/Avalonia/Core/Engine。
- **内容**（模块开发者可直接调用）：
  - `ColorUtil`：PackBgra/R/G/B/A、Premultiply/Unpremultiply（自 Core 迁移）
  - `GeometryAlgorithms`：Bresenham 线段、硬边/软边笔刷 stamp（径向 alpha 衰减）、多毛刷痕（平行毛线组，毛宽/偏移中间大两边小）、圆/椭圆
  - `FloodFill`：魔棒选区（颜色容差 BFS）+ 区域填充
  - `Scaling`：最近邻 / 双线性缩放
  - `ColorTransforms`：灰度（亮度公式）、色彩量化（动漫）、Sobel 边缘
  - `Convolution`：高斯模糊 / 锐化
- **迁移计划**：Core.ColorUtil → Algorithms（Core 引用 Algorithms）；fptm 的 FloodFill/Stamp 上移到 Algorithms；idphoto 滤镜算法后续逐步上移（2.1 完成基础，滤镜算法迁移随模块重构进行）。
- tie 预留：tie 宿主（TieHost）同样经 Algorithms 提供算法能力，tie 滤镜脚本可调用。
